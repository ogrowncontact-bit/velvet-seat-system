# Seat Reserve

PROMPT COMPLETO — SaaS DE RESERVAS PREMIUM PARA RESTAURANTES

Create a modern SaaS web application for restaurant reservation management inspired by OpenTable, but with a much more elegant, premium, minimalistic and futuristic design.

The platform should focus on automation, table management, WhatsApp communication, customer experience and reducing no-shows.

The design style should feel like a mix between:

Stripe

Airbnb

Notion

Linear

Apple-like interfaces

The application must be responsive for desktop, tablet and mobile.

MAIN GOAL

Create a complete booking and restaurant operations platform where restaurants can:

manage table reservations

organize table layouts visually

receive online bookings

confirm reservations automatically via WhatsApp/SMS

collect booking deposits

reduce no-shows

create customer profiles

manage VIP clients

track analytics

automate communication

APP NAME

Temporary name:
"SeatFlow"

Allow easy future rebranding.

USER TYPES

Restaurant Owner/Admin

Restaurant Staff/Hostess

Customers making reservations
